## Domain transitions and irreversible inertness

Every serialized effective source transaction has old/new contact Domain snapshots. Obtain checked next revision **before** source mutation, as existing coordinator contract requires. Compute new canonical context/holds/root ticket scalars from actual committed source. Before retiring old root ownership, mark occupied associations `inert=true` if their stamped Domain does not match the new intended current Domain. If source becomes unsupported/LeavingClassic, mark all occupied inert. This is scalar invalidation, not controller.cancel; contact entries/coordinates/moved/baseline are preserved. Once inert, a record never becomes live again until end retires it or an independently authorized whole cancel clears it. Returning to identical context cannot resurrect a contact that crossed a domain change. [task-3i3-router-execution-slices.md, § Common contract]

This transaction invalidation hook is mandatory on root replacement, projected draft appearance/disappearance/replacement, base mode/section/world/confirmation context change, current hold replacement and guide/shell context change. Ordinary same-domain focus, text, camera orbit/zoom, redraw, preference value or viewport revision does **not** invalidate merely because revision advanced. Full event/current/publication revision checks still apply to every dispatch; the sidecar answers contact-origin domain, not whether an old frame is current. Actual modal/guide hold identity lifetimes remain revision-derived, without new counters. Partial source effects that committed despite reported failure still execute this hook before reprojection. Rejected preadmission transaction does not invalidate. [task-3i3-router-concrete-focus-owner-addendum.md:81; task-3i3-router-focus-conversion-fix1.md:57]

As a defensive guard every pointer operation also compares scalar stamp to current Domain and marks mismatching existing record inert before any gesture dispatch. This catches missed synchronization as failure, not silently repairs a missing transaction hook; implementation fixtures must prove all legitimate transactions invoke it. Never change only the stamp to retarget an existing raw contact into new source.
