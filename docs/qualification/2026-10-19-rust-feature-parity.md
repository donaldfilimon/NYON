## Dependency order and evidence boundaries

1. Cube topology, roles, navigation (existing Classic Rust routes are not a new strategic generator).
2. Planet state/commands/phases/history/replay with exact canonical envelopes and receipts.
3. Coordinated state, shared budget, snapshot leases, single publication, rollback/fault/replay. Existing in-progress source is not proof of completed coordination.
4. Seeded metadata/config/generation/wire/setup ownership/policy/CLI; the existing coordinated-genesis equivalence gap remains open.
5. Catalog/allocator ledger/metadata; these implement proposals and codecs, not atomic native or IndexedDB persistence.
6. Runtime/store/render/tool integration using the retained Rust platform, with no existing-profile migration.
